# core/gc/ — 引擎级统一 GC（独立子系统）

对应设计 §3.2。interp 与 JIT 后端共用同一托管堆与回收器，管**栈与对象**，单一对象身份。

- 根扫描：精确根扫描（interp/JIT 通用栈图）。
- 回收策略：分代 + 移动式（新生代复制 / 老年代整理）。
- 协程栈：GC 管栈 + 对象（M:N 可迁移栈是 GC 根来源与移动载体）。
- 与路线 A：A 无 GC（确定性释放保持现状），GC 是路线 B 独有能力。
